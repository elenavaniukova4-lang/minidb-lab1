# MiniDB

Лабораторная работа №1 по курсу «Базы данных». MiniDB — небольшая СУБД, которая хранит таблицы в файлах на диске.

## Запуск

Нужен Python 3, дополнительные библиотеки не нужны. Запуск: python3 demo.py

Программа создаёт три таблицы, загружает тестовые данные (5 наборов данных, 5 моделей, 20 экспериментов), показывает работу операций и проверяет, что данные сохраняются после перезапуска. Файлы хранилища появляются в папке data.

## Архитектура

Программа состоит из трёх частей:

- engine.py — главный класс MiniDB. Проверяет ключи и выполняет операции с таблицами.
- storage.py — работа с файлами: читает и записывает данные в папке data.
- type_serializer.py — превращает числа и строки в байты и обратно.

## Таблицы

- datasets — наборы данных (id, name, task, size)
- models — модели (id, name, version)
- experiments — эксперименты (id, dataset_id, model_id, accuracy, status)

В таблице experiments поля dataset_id и model_id ссылаются на datasets и models.

## Как хранятся данные

В папке data лежит файл catalog.dat с описанием всех таблиц (обычный текст) и по одному бинарному файлу на каждую таблицу. Строки в таких файлах записаны подряд. Целое число занимает 4 байта, дробное — 8 байт, строка хранится как длина (4 байта) и сами символы.

## Что реализовано

- создание таблиц
- добавление, выборка, изменение и удаление строк
- проверка уникальности первичного ключа
- проверка внешних ключей
- сохранение данных между запусками
